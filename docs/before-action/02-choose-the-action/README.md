很多操作失误，不是因为判断完全错误，而是因为动作选错了。

这一部分要解决的是：你现在到底准备做什么。买入、卖出、加仓、减仓、清仓，看起来都叫操作，但背后的逻辑、风险和条件完全不同。

- [减仓和清仓也不是一回事](/before-action/choose-the-action/reduce-is-not-exit-all/)
- [动作模糊时，通常说明不该动](/before-action/choose-the-action/unclear-action-means-do-not-move/)
