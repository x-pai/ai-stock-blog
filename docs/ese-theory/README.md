### 市场的真相：熵与欲望

长久以来，金融学界一直试图用“有效市场假说”或“价值投资”来驯服股市。他们把市场描绘成一台精密的模拟计算机，认为股价会围绕价值波动。

**这简直是人类傲慢的极致点。**

真实的股市，是一个**熵增系统**。它是数以亿计的“感觉人”在贪婪与恐惧中交织出的能量场。股价的波动，本质上是能量在不同主体间的转移。当筹码从有序的主力手中流向无序的散户手中时，熵增便发生了。坍缩，是系统回归平衡的唯一方式。

### 进化，还是作为“供养者”消亡？

在自然界，弱肉强食是唯一的真理。在股市中，90%的人注定要亏损，因为他们的生物本能——对盈利的贪婪和对亏损的恐惧——正是这个系统赖以生存的**养料**。我称这群人为“**供养者**”。

如果你依然依赖直觉交易，依然在酒桌上打听消息，依然在亏损时祈祷奇迹，那么你就是这个生态链底层的生物质能。你的亏损，正是机构和大户进化的能量来源。

本书存在的唯一目的，就是帮你完成**物种跨越**。
