**目标：** 将“候选池 → 信号 → 下单 → 监控 → 退出”这一整条链路自动化或半自动化，实现策略的可重复执行。  

**典型流程：**

1. **候选池生成**：  
   - 基本面过滤：剔除流动性过差、财务明显异常的标的；  
   - 结构过滤：优先选择有清晰中枢与趋势结构的股票；  
   - 情绪过滤：剔除情绪已极端过热的标的。  
2. **入场信号识别**：  
   - 势能条件：筹码集中、低位蓄能、中枢突破；  
   - 情绪条件：情绪从冷到暖，但未到极端狂热；  
   - 分形条件：周/日/60 分钟多周期共振。  
3. **下单与风控**：  
   - 计算技术止损位（中枢下沿/前低/均线）；  
   - 逆推单笔风险 R，得到仓位大小；  
   - 生成具体委托指令（限价/市价/分批建仓）。  
4. **持仓监控**：  
   - 守株规则：在预设结构与盈亏比逻辑未被破坏前，不做主观干预；  
   - 趋势破坏或熵增预警触发时，自动减仓或平仓。  

在理想状态下，人工的角色被限定为：

- 设计和优化 ESE 规则本身；  
- 审核模型更新与参数调整；  
- 在极端行情下按预案执行“人工熔断”。
