热力学第二定律告诉我们：**封闭系统的熵（无序度）总是趋向增加。**  

一个热咖啡放在桌上，会慢慢冷却，与环境温度趋于一致；  

一个强控盘的股票，也终会从“少数人掌控”走向“多数人持有，价格混乱”。

在市场语言中，可以把熵理解为：

- 持筹的分散程度；  
- 参与者预期的一致/分裂程度；  
- 价格与成交量的混乱程度。  

当一只股票处于高度控盘阶段时：

- 筹码高度集中，熵非常低；  
- 价格波动平缓，甚至长时间横盘；  
- 参与者预期相对简单：要么“等拉升”，要么“不动”。  

而当派发接近尾声时，你会看到完全相反的画面：

- 筹码分散在无数散户/短线手中，熵急剧增大；  
- 当日振幅剧烈、成交量爆炸，价格对任何消息都过度敏感；  
- 预期撕裂：有人坚信“这只是回调”，有人恐慌砍仓，有人加仓“抄底”。  

**演化过程：** 

  - 低熵期（吸筹）： 筹码集中，结构有序，能量积蓄。
  - 做功期（拉升）： 势能释放，斜率变大。
  - 熵增期（派发）： 筹码由主力（有序）流向散户（无序），系统陷入混乱，最终坍缩。

**熵增必然公理的核心含义是：**

- 再完美的控盘，也只能暂时对抗熵增；  
- 所有主力都必须完成派发，区别只在于：优雅地完成，还是在踩踏中崩盘。  

**交易者实践要点：**

- 不要沉迷于“神秘庄家”的阴谋论：他们同样被熵增法则约束；  
- 你的任务不是猜阴谋，而是观测熵——一旦熵增迹象出现，就要考虑自己是否正在成为最后一棒。
