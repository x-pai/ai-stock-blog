**目标：** 找到价格长期反复争夺、量价密集、筹码高度堆积的“能量蓄水池”，以及真正意义上的突破点。  

**核心思路：**

中枢（Consolidation Zone）是多空能量交换的平衡区。

**方法融合：**

- 缠论中的“中枢”：若干走势单元在价格区间上的重叠；  
- 筹码分布中的“峰”：持仓成本高度集中的价格带；  
- 成交量与换手率：能量进出该区间的速度。  

**确认“逃逸点”：**

我们要观测的是**“第三类买点”**：即股价跳出中枢后，回踩中枢上沿而不进入。

- 一只股票在某个价格区间反复震荡数月，成交量稳定、波动率收窄；  
- 筹码图显示绝大部分筹码集中于此区间，外侧筹码稀少；  
- 突破该区间上沿并站稳，往往意味着“势能爆发”的起点。  

中枢蓄能分析的本质，是回答：  

> “这一次突破，是在空气中乱蹦，还是冲出了一个巨大的能量蓄水池？”
